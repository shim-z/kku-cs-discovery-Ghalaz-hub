About the prototype

Computer science, explained as a learning journey.

This page uses a structured narrative instead of a long institutional text block, helping visitors understand purpose, progression and values quickly.

Who we are

A student-centered computing environment

The Department of Computer Science is represented here as a place where analytical thinking, software construction and responsible technology practice meet. The prototype intentionally focuses on what a prospective or current student needs to understand first.

Prototype design principle

Every major section should answer one question, use one visual hierarchy and offer one obvious next step.

1

Foundations

Build computational thinking, programming discipline and core problem-solving habits.

2

Systems

Connect algorithms, data, software engineering and the infrastructure that supports digital services.

3

Application

Translate knowledge into projects, prototypes and tested solutions for real user needs.

4

Professional practice

Communicate clearly, work ethically, test rigorously and improve through evidence and feedback.

Design values

What the interface prioritizes

The web design itself demonstrates Web Engineering choices: usability, navigability, performance, maintainability, accessibility and security awareness.

U

Usability

Short sections, visible headings, high contrast and predictable controls reduce effort for first-time visitors.

N

Navigation

The same menu appears on every page, with the current page highlighted and a skip link for keyboard users.

S

Security awareness

The prototype does not transmit or claim to store sensitive data on a remote server; production forms would use a secure server-side endpoint.
