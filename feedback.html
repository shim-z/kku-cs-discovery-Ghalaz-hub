Usability feedback

Help improve the next increment.

Rate the prototype after visiting Home, About Us and Contact. The questions focus on usability, navigation, content clarity, visual design and confidence.

How to test

Three short tasks

1

Find the college overview

Use the menu to reach About Us and identify the learning journey.

2

Locate a contact route

Open Contact and identify the fields needed for an inquiry.

3

Return here

Complete the ratings and suggest one improvement for the next version.

For this prototype, responses are stored only in the current browser using local storage. A production system would use a secure authenticated endpoint and a documented retention policy.
